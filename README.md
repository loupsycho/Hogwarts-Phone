# Hogwarts Phone

Application mobile de téléphone virtuel pour l'univers de Poudlard.

## Stack
- React
- TypeScript
- Vite
- CSS responsive

## État du projet
Cette première base prépare l'interface et la navigation. La connexion Discord, les comptes, les personnages et les données seront ajoutés ensuite avec un backend indépendant.

## Développement
```bash
npm install
npm run dev
```
